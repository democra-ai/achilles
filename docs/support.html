Frequently Asked Questions

How do I get started?

Launch Achilles Vault and the backend server will start automatically. The dashboard shows your projects, vault items, and server status. Create a project first, then start adding secrets to it.

The server shows as "Offline" — what should I do?

Click the Start button in the app. If the issue persists, try quitting and relaunching the app. The backend server runs locally on your machine and requires no internet connection.

Where is my data stored?

All data is stored locally on your device in the ~/.achilles/ directory. Your secrets are encrypted with AES-256-GCM. No data is ever sent to external servers.

How do I connect AI tools to the vault?

Achilles Vault includes a built-in MCP (Model Context Protocol) server on port 8901. Compatible AI tools like Claude and Cursor can connect to it directly. Go to Settings in the app to see your MCP configuration.

Can I use Achilles Vault with multiple projects?

Yes. Create separate projects in the Projects tab. Each project can have its own environments (e.g. development, staging, production), and secrets are scoped to project and environment.

How do I back up my vault?

Your vault is a local SQLite database at ~/.achilles/vault.db. You can back up this file along with ~/.achilles/master.key. Keep your master key safe — it is required to decrypt your secrets.

Troubleshooting

  • If the app won't start, try restarting your Mac and launching again.
  • If the backend server won't start, check that no other process is using port 8900.
  • If secrets fail to decrypt, ensure your ~/.achilles/master.key file is intact.
  • For the Chrome extension, make sure the desktop app is running first.
